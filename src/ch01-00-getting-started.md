# Memulai

Mari mulai perjalanan belajar Rust kamu! Banyak hal yang harus dipelajari, tapi
setiap perjalanan pasti dimulai dari suatu tempat. Di bab ini, kita akan membahas:

- Memasang Rust di Linux, macOS, dan Windows
- Menulis program yang mencetak `Hello, world!`
- Menggunakan `cargo`, package manager dan sistem build milik Rust
