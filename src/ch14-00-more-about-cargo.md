# Lebih Lanjut Tentang Cargo dan Crates.io

Sejauh ini, kita baru memakai fitur paling dasar Cargo untuk membuild,
menjalankan, dan mengetest kode kita, padahal Cargo bisa jauh lebih banyak. Di
bab ini, kita akan membahas beberapa fitur lain yang lebih lanjut untuk
menunjukkan cara melakukan hal-hal berikut:

- Menyesuaikan build kamu lewat release profile.
- Menerbitkan library di [crates.io](https://crates.io/)<!-- ignore -->.
- Mengatur proyek besar dengan workspace.
- Memasang binary dari [crates.io](https://crates.io/)<!-- ignore -->.
- Mengembangkan Cargo dengan perintah kustom.

Cargo bahkan bisa lebih banyak lagi daripada yang kita bahas di bab ini, jadi
untuk penjelasan lengkap semua fiturnya, lihat [dokumentasinya](https://doc.rust-lang.org/cargo/).
